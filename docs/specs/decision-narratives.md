- RecommendationCard shows one supplied recommendation, complete option value,
  reported confidence/evidence, rationale, benefits, caveats and alternatives.
  An explicit available action requests that exact recommendation; no default
  approval, scoring, recommendation computation or external execution occurs.
- TradeoffPanel shows ordered supplied options with complete values/evidence and
  separate benefits, costs and uncertainties. An empty list states that no items
  were supplied. It never sorts, scores or chooses an option. Existing selector/
  comparison components own choice interactions; its optional action requests
  review of this exact analysis.
- DecisionMemo shows context, reported status, supplied considered options,
  reported decision, rationale, risks and reported follow-up states. A decided
  memo must identify a current option; a deferred memo has no chosen option.
  UI interaction cannot change reported decision or mark follow-ups complete.
- ReasoningSummary displays a consumer-supplied user-facing overview, findings,
  explanations, confidence/evidence and limitations. It is not an internal model
  trace and never requests, reconstructs or exposes hidden reasoning.
