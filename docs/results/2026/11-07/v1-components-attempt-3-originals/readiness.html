Structured tool result

import { ToolCallCardSchema } from "@mcpcn/schemas";
import { createStructuredResult } from "@mcpcn/server";

export function reviewedResult(candidate: unknown) {
  const data = ToolCallCardSchema.parse(candidate);
  return createStructuredResult("tool-call-card", data);
}

Security contract

Previews use authored data and consumer callbacks. Applications own authorization, persistence, tool execution and explicit model-context publication.

Declared model-visible fields: decision, userInput

Private fields: internalId, rawPII

Declared consumer tool intents: configuredTool

Destructive intent: No by default

Host and keyboard behavior

Host integration uses the consuming application's runtime provider. Native inputs, buttons, links and semantic tables expose the local interactions shown above. External-host compatibility and full accessibility conformance require their own acceptance evidence.
